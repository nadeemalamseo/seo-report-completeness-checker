CAPABILITIES

Built for complete, actionable audit records.

E

Evidence completeness

Detect missing or weak evidence so findings have a concrete basis.

R

Recommendations

Check that actionable recommendations are present instead of generic placeholders.

S

Status tracking

Validate implementation statuses, priorities, impacts, duplicates, and due dates.

V

Verification

Require verification evidence when findings reach READY_FOR_VERIFICATION or VERIFIED.

WORKFLOW

From existing audit to action-ready report.

EXISTING AUDIT → CSV / JSON → COMPLETENESS CHECK → FINDINGS → ACTION → IMPLEMENTATION → VERIFICATION
QUICK START

Run the checker in four steps.

1

Install

Use Python 3.10+ and run python -m pip install -e ..

2

Prepare input

Use an existing CSV or JSON SEO audit report with the documented fields.

3

Run a check

Run seo-report-check your-report.csv from the repository directory.

4

Review & act

Fix missing or inconsistent fields, implement actions, then record verification.

SCOPE

Deterministic validation—not an SEO oracle.

The checker evaluates report completeness and internal consistency.

It does not crawl websites, call search-engine APIs, verify live HTTP responses, assess strategic correctness, predict rankings or traffic, or guarantee indexing or search visibility. Weak evidence/recommendation checks are deterministic heuristics, not expert or AI judgments.
