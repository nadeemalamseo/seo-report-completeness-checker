What it checks

Required fields

Detects missing issue, URL, evidence, impact, priority, recommendation, and implementation status.

Consistency

Checks duplicate IDs/findings, supported values, verification lifecycle rules, and status conflicts.

Action tracking

Flags invalid dates and overdue findings while preserving deterministic, offline behavior.

Quality heuristics

Identifies generic evidence or recommendations using simple deterministic rules.

Quick start

python -m pip install -e .
seo-report-check examples/complete-report.csv
seo-report-check examples/incomplete-report.csv --json
seo-report-check examples/incomplete-report.csv --strict --today 2026-09-29

Clear setup guide

1. Get the tool

Download the v0.1.0 ZIP or clone the repository.

2. Install

Use Python 3.10 or newer, then run python -m pip install -e ..

3. Prepare your report

Provide an existing CSV or JSON SEO audit report using the documented fields.

4. Run the checker

Run seo-report-check your-report.csv. Use --json for machine-readable output and --strict to promote warnings.

Supported input

CSV

Pass a CSV report directly to the CLI. UTF-8 and UTF-8 with BOM are supported.

JSON

Pass a JSON list of finding objects, or an object containing a findings or rows list.

Verification lifecycle

verification becomes required when implementation_status is READY_FOR_VERIFICATION or VERIFIED. It is optional for OPEN, IN_PROGRESS, BLOCKED, and WONT_FIX.

Scope and limitations

This tool validates report completeness and internal consistency. It does not crawl websites, call search-engine APIs, verify live HTTP responses, assess whether an SEO recommendation is strategically correct, predict rankings or traffic, or guarantee indexing or search visibility.

Evidence and recommendation quality checks are deterministic heuristics, not expert or AI judgments.
